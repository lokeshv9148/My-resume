# Lokesh V — AWS Cloud & DevOps Portfolio

## Files
- `index.html` — page structure and portfolio content
- `style.css` — responsive layout, glass panels, gradients, animation and mobile styling
- `script.js` — mobile navigation, theme toggle, typewriter heading, project filters, email copy and animated particles

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. For a local development server, open the folder in VS Code and use the Live Server extension.

## Before publishing — personalize these items
- Confirm the MCA dates/status and update the education line if needed.
- Add dates and details for the Dotch Endeavours internship.
- Replace the AWS practice placeholder card with a lab you have actually completed. Add architecture screenshots and a GitHub repository link if available.
- Add your verified certificates and certificate links.
- Add a resume PDF in this folder and add a link in the About section if you want a resume download button.
- Add LinkedIn and GitHub links when ready.
- Confirm the phone number and email shown in the contact section before publishing.

## Deploy
You can host this static website with Amazon S3 static website hosting or use AWS Amplify Hosting. For a public production site, configure HTTPS and a custom domain (for example, with CloudFront and Route 53 if using S3).
